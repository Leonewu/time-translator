Time Translator

Privacy Policy

Last updated: September 30, 2026

Data and local storage

The extension stores your API key, provider and model settings, timezones, automatic detection preference, custom triggers, blocked sites and optional Magic Code in your browser's local extension storage. You can edit them in the popup or remove the extension to delete its local data. We do not sell your data.

Requests to your provider

With automatic detection enabled, selecting and releasing text that passes a local time-candidate check can automatically send the selected text to your configured AI provider. Manual conversion and the online test also send the selected or test text to that provider. A Gmail message timestamp may be sent with selected text to interpret relative dates; the entire message and page are not sent. Requests use your stored API key. When you change providers, enter a key, or refresh models, the extension may request the model list from that provider with your API key, without selected page text. Provider handling is governed by its own terms and privacy policy.

Feedback and contact

Feedback links open your email app with a draft. From a conversion tooltip, the draft includes only the selected text and displayed result or error; review it before sending. No report is sent in the background. We do not send your API key, browsing history or full page to our own server. Contact us via GitHub issues or reon.hypr@gmail.com.

隐私政策

最后更新：2026 年 9 月 30 日

数据与本地存储

API Key、服务商与模型配置、时区、自动检测开关、自定义触发词、屏蔽网站及可选的 Magic Code 保存在浏览器本地扩展存储中。可在弹窗内修改，或移除扩展以删除本地数据。我们不出售用户数据。

发送给你选择的服务商

开启自动检测后，选中文字并松开鼠标，如通过本地时间候选检查，文本可能自动发送给配置的模型服务商。手动转换和在线测试也会将选中或测试文本发送给该服务商。为解释相对日期，可能同时发送 Gmail 邮件时间，不发送整封邮件或整个网页。请求使用本地保存的 API Key。切换服务商、填写 Key 或刷新模型时，插件可能使用 API Key 向该服务商请求模型列表；此请求不包含网页选中文字。服务商如何处理数据受其条款和隐私政策约束。

反馈与联系

反馈入口会打开邮件草稿。转换 Tooltip 的草稿仅包含选中文字和显示的结果或错误，请确认后再发送。插件不会在后台发送反馈，不会向我们的服务器发送 API Key、浏览历史或整页内容。如需联系，可在 GitHub 提交 issue，或发送邮件至 reon.hypr@gmail.com。
