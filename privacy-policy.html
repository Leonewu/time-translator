隐私政策

最后更新：2026 年 8 月 21 日

我们处理哪些信息

  • 你主动选中的文本：仅在你发起转换或在线测试时处理。
  • 模型配置和 API Key：保存在你本机浏览器的扩展存储中，用于向你选择的模型服务商发起请求。
  • 模型列表请求：当你切换服务商或点击刷新模型时，扩展会向当前服务商请求可用模型名称；这类请求不包含你选中的网页文本。
  • 时区偏好、插件开关和自定义触发词：保存在本机，用于提供对应功能。

信息如何传输

发起转换时，选中的文本会直接发送到你在扩展面板中选择的模型服务商。刷新模型列表时，扩展会将 API Key 用于请求该服务商的模型列表。Time Translator 不会把整页内容、浏览历史或 API Key 发送到维护者自己的服务器，也不出售用户数据。

本地存储与删除

扩展设置使用浏览器的本地扩展存储保存。你可以在扩展面板中修改配置，或在浏览器扩展管理页面移除扩展以删除这些本地数据。

第三方服务

模型服务商对请求数据的处理受其自身隐私政策约束。使用在线模型前，请确认你选择的服务商及其 API 使用条款适合你的场景。
